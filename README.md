# 作業員名簿管理システム（全建統一様式第5号）
会社・作業員・元請名簿様式を登録し、顔写真付きの作業員名簿をPDF出力するWebアプリ。
## 使い方
`index.html` をブラウザで開く（またはGitHub Pagesで公開）。ビルド不要。
- 会社 → 作業員（写真アップロード可）→ 元請名簿様式（元請名・工事名・出力項目）を登録
- 「名簿PDF出力」で会社・様式・作業員を選び、印刷ダイアログで「PDFに保存」（A4横）
## 構成
`index.html` / `app.js`（ロジック） / `style.css`（画面・印刷）
## 注意・今後の拡張
- データはブラウザのlocalStorageのみに保存（端末間で共有されません）。複数人利用はバックエンド(DB)化が必要。
- 個人情報を含むため、リポジトリはprivate推奨。
